# AE All Pattern 0.2.6 / 0.2.6-beta.1

**升级前请备份存档 / Back up your world before upgrading.**

- 1.21.1 NeoForge: **0.2.6**, Java 21, NeoForge 21.1.233+, AE2 19.2.17+, GuideME 21.1.1+.
- 1.20.1 Forge: **0.2.6-beta.1**, Java 17, Forge **47.1.25+** (lowered from 47.4.20), AE2 15.4.10+, GuideME 20.1.7+. This port remains beta.

## Changes / 更新

- Right-click a placed All Pattern Linker to configure blocking (default off), smart batch dispatch (on), and automatic output return (on). Settings persist per Linker. Smart dispatch batches already-owned crafts, up to 64 per tick; it does not multiply items for free.
- 全样板连接器新增阻挡模式、智能翻倍、产物自动回收设置，默认分别为关、开、开；修复设置变更后的样板刷新及忽略输入 NBT 的实际投料校验。
- Support the separate pattern catalog in publicly available Neo ECO 21.2.0-beta3; retain legacy ECO support, remove duplicate marker publication, and guard callbacks after node destruction. No publicly available beta5 artifact was found for verification.
- 修复无用之物 1.21.1 的 ME 样板总成不能插入聚合样板，保留多方块结构与配方校验。Forge 版该模组目前没有这一多方块。
- Forge configuration-screen registration now uses an API compatible with 47.1.x; the minimum runtime is separate from the development Forge version.
- Includes the earlier 0.2.4/0.2.5 GuideME guide, Masterful Machinery controller-aware scanning, and opt-in ignore-input-NBT setting. Only enable NBT ignoring when the machine accepts those variants; named, enchanted or damaged items may be consumed.

## Verification / 验证与限制

- NeoForge: 263 unit tests; Forge: 257 unit tests. Both release builds and JAR checks passed.
- 73 registered no-GUI GameTests on each version. Optional-mod tests skip when the target mod/feature is absent; this is not universal modpack coverage.
- Real ECO publication and fresh-process save/reopen tests: Neo ECO 21.2.0-beta3, legacy 21.1.1, Forge ECO 20.3.0. Real formed Useless Mod 2.3.7.2 assembly publication, input consumption and exact output return tested on 1.21.1.
- The reported need to remove/reinsert patterns after rejoining was **not reproduced** in these fixtures. This release does not claim to fix every such report; please provide logs and a reproducible save if it persists.
- Forge ECO 20.4.2's upstream Mixin startup issue is not claimed fixed here. Other installed mods may require a newer loader even though AE All Pattern only requires Forge 47.1.25.
