# AE All Pattern 0.2.7 / 0.2.7-beta.1

**升级前请备份存档 / Back up your world before upgrading.**

- **1.21.1 NeoForge: 0.2.7** — Java 21, NeoForge 21.1.233+, AE2 19.2.17+, GuideME 21.1.1+.
- **1.20.1 Forge: 0.2.7-beta.1** — Java 17, Forge 47.1.25+, AE2 15.4.10+, GuideME 20.1.7+. The Forge port remains beta. AE2 UELM 15.5.5 is also tested.

## Changes / 更新

- 修复 Issue #23：1.20.1 搭配 AE2 UELM 15.5.5 时，合成确认菜单 Mixin 因订单数量由 `int` 改为 `long` 而启动崩溃。已在专服成功复现并修复。
- Fix the startup crash with AE2 UELM 15.5.5. Routing-policy recalculation now lets AE2 retain its own order data, supporting upstream's integer amounts and UELM's long amounts. The corresponding menu change is synchronized to 1.21.1.
- 修改合成确认菜单中的路由设置后，保留完整订单数量和缺料报告；添加 UELM 30 亿数量订单的回归测试。
- “移除处理配方催化剂”现在保存 JEI／EMI 明确声明的催化剂证据，以及 EMI 提供的保证原样返还信息。普通材料、消耗耐久的工具和不确定返还物仍保留为输入；已有催化剂标签支持保留。
- Preserve explicit JEI/EMI catalyst evidence in aggregate catalogs. Tool removal requires reliable viewer evidence; keep the actual reusable tool in the machine. An item also listed as a recipe output is conservatively retained as an input.
- Add dedicated-server tests through AE's real confirmation menu for aggregate priority, short/long path selection and order-preserving recalculation, plus a 12,000-reachable-recipe planning test. Add AE2 UELM 15.5.5 to the Forge no-GUI CI matrix and verify the loaded AE2 version.

## Upgrade / 升级

- **客户端与服务端须一起更新。** 催化剂证据传输使用网络协议 2；旧版客户端不能与本次服务端混用。
- **Update clients and servers together.** The catalyst-evidence transport uses network protocol 2.
- Existing saved catalogs default missing catalyst evidence to false. Rescan the machine or let the existing startup catalog refresh finish to obtain viewer evidence.
- 不会自动给机器补充模具或工具。没有可靠催化剂声明／原样返还信息的配方，仍需机器适配或上游配方查看器支持。

## Validation / 验证

- Both versions passed clean unit-test, release metadata, JAR-content and build checks.
- Dedicated-server `--nogui` runs passed **77/77 required GameTests** on Minecraft 1.20.1 with upstream AE2 15.4.10, Minecraft 1.20.1 with AE2 UELM 15.5.5, and Minecraft 1.21.1 with AE2 19.2.17.
- These runs include confirmation-menu policy changes, missing-material reporting, a 3,000,000,000-item UELM order and the 12,000-pattern planning fixture. Optional-mod tests may skip their assertions when the corresponding mod is absent.
- This hotfix was validated without launching a game client. It does not claim a full reproduction of the reporter's entire modpack.
