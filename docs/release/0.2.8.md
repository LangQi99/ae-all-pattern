# AE All Pattern 0.2.8 / 0.2.8-beta.1

**升级前请备份存档 / Back up your world before upgrading.**

- **1.21.1 NeoForge: 0.2.8** — Java 21, NeoForge 21.1.233+, AE2 19.2.17+, GuideME 21.1.1+.
- **1.20.1 Forge: 0.2.8-beta.1** — Java 17, Forge 47.1.25+, AE2 15.4.10+, GuideME 20.1.7+. The Forge port remains beta.

## Changes / 更新

- 修复 #24：聚合样板默认只搜索产物；搜索框旁可切换“产物 / 原料 / 全部”。搜索、分页与全选/取消全选均遵循所选范围，覆盖整个配方目录。
- Fix #24: Aggregate Pattern search defaults to outputs, with separate Outputs, Inputs and All controls. Filtering and bulk selection cover the complete catalog across pages.
- 跟进 #25：合成确认菜单打开时就检测在线天枢路由器，并在 AE 同步界面字段前刷新可用状态；菜单保持打开时，路由器断开、重连也会同步按钮状态。保留玩家当前订单的临时路线偏好。
- Initialize routing availability before planning and refresh it before AE GUI synchronization. A router joining or leaving the network updates the confirmation controls without requiring a new order.
- 修复 Forge CI 把新增后的 80 项测试与过期的“77 项”断言比较而误报失败；UELM 15.5.5 测试依赖改从官方 GitHub Release 获取。

## Upgrade / 升级

- **客户端与服务端必须一起更新。** 本次使用搜索范围传输协议 3，不能与协议 2 的旧版混用。
- **Update clients and servers together.** Scoped search uses network protocol 3.
- 天枢路由器只负责订单规划；实际合成仍需正常的 AE 合成 CPU。
- Tianshu is a route planner; actual crafting execution still requires an ordinary AE crafting CPU.

## Validation / 验证

- Both release candidates passed clean `check build`, including unit tests, metadata checks and release-JAR contents checks.
- All **80 required no-GUI GameTests** passed independently on 1.21.1 / AE2 19.2.17, 1.20.1 / AE2 15.4.11, and 1.20.1 / AE2 UELM 15.5.5. UELM coverage includes preserving a 3,000,000,000-item order when routing preferences are changed.
- The new routing synchronization regression fails before the fix and checks initial availability plus full/delta AE GUI updates.
- The production Forge GUI gate uses a real terminal and server packets to check initial availability, popup interaction, router disconnection and reconnection. Publishing requires this gate to pass.
- The full Project Infinity modpack from #25 has not been reproduced. Keep that report open for confirmation with the new Forge beta; these checks establish the isolated routing-state fix.
