# 生成器与聚合样板

1. 客户端安装 JEI，或 EMI 加 TooManyRecipeViewers。
2. 手持全样板生成器，**潜行右击机器或控制器**。
3. 将生成的聚合样板放入 AE2 样板供应器或受支持的附属供应器。
4. 给机器供能，接好物品、流体输入与输出，并把成品送回 ME 网络。

工作台配方交给分子装配室。处理配方仍需真实机器；生成样板不会替你建造机器或提供能量。

## 管理配方目录

手持聚合样板右键打开管理面板，通过标签页切换配方选择和编码设置。输入是配方需要的材料，输出是配方产生的成品。搜索筛选的是配方目录，不是机器背包。

大型目录保存在服务端样板库并分页传输。迁移存档时要保留完整世界数据，不能只复制样板物品；更新模组前请备份。每张实体样板单独保存勾选状态。

取消勾选后，对应配方不再发布。删除流体、化学品或催化剂等编码选项可能让样板与实际机器要求不符，只有自动化系统另外提供这些材料时才应开启。

**忽略输入 NBT** 默认关闭。仅对加工物品输入生效：同种物品忽略 NBT/组件（包括名称、附魔与耐久），实际投入仍保留原数据。不会放宽流体、化学品或工作台配方的合法性检查，也不能让机器接受本来不合法的材料。仅在目标机器允许这些变体时开启；它与忽略产物 NBT 是独立选项。
