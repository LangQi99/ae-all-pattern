# AE 全样板

根据你的用途选择：

- [生成器与聚合样板](aggregate_patterns.md)：把机器配方收进实体样板，再放进样板供应器。
- [全样板链接器与绑定器](pattern_linker.md)：通过受支持的机器适配器发布实时虚拟样板，不需要实体样板。
- [天枢样板路由器](tianshu_router.md)：下单时在同一产物的多种配方之间选择路线。
- [多方块与排查](multiblocks.md)：控制器选择、配方查看器和投料注意事项。

用一本书和一个赛特斯石英水晶合成这本指南，手持右键打开。也可在物品上悬停并按 GuideME 设置中的“打开指南”快捷键进入对应页面。指南内支持搜索与目录导航。

聚合样板不要求安装链接器。路由器对两种流程都属于可选优化，不是合成 CPU。
