# 全样板链接器与绑定器

链接器通过受支持的机器适配器发布**实时虚拟处理样板**。它不同于生成器：生成器读取配方查看器目录，制作实体聚合样板。

1. 将全样板链接器接入有电、且有空余频道的 ME 网络。
2. 手持全样板绑定器，**潜行右击链接器**选择它。
3. 继续潜行右击受支持的机器完成绑定；紫色轮廓表示绑定成功。
4. 给机器提供所需能量，并将成品送回网络。

链接器占用一个频道，消耗 2 AE/t。它先接管并缓存输入，再向绑定的机器投料。绑定器可重复使用，选定链接器后能连续绑定多台机器。

## 哪些机器能绑定？

绑定需要已实现的机器适配器。JEI 能显示某台机器的配方，**不代表链接器就能绑定它**。普通自定义多方块优先使用生成器配合样板供应器。

异常时检查链接器是否在线、频道是否足够、机器所在区块是否加载，以及距离和跨维度配置是否允许绑定。
