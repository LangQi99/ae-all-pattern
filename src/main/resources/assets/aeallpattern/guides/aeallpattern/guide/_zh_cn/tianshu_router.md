# 天枢样板路由器

当多个样板能生产同一物品时，路由器帮助选择配方路线。**它不是合成 CPU、样板供应器，也不是加工机器。** 仍需普通 AE2 合成 CPU 和实际生产设备。

1. 将路由器接入同一个 ME 网络，确保在线。
2. 右击路由器设置网络默认的路线偏好。
3. 在合成终端下单；合成确认界面可以为本次订单临时调整偏好。

可行性始终第一。其他偏好可以优先选择依赖链较短、材料余量较多、单次产出较高、设备等待较少的路线，也可调整顺序、反向或关闭。

聚合样板默认优先级为 -1，因此优先级为 0 的手动编码样板会优先采用。

## 高级资格设置

“副产物可独立下单”默认关闭。开启后，可能为了一个副产物而启动整条昂贵配方。

“循环增殖”处理有净增益的直接循环，但仍需要真实启动种子；路由器不能凭空制造第一个材料。

如果下单界面没有路线设置，检查路由器是否在同网且在线。路由器本身不提供机器配方，仍需实体样板或受支持的链接器绑定。
