# AE All Pattern

Choose the workflow that fits your setup:

- [Generator and Aggregate Patterns](aggregate_patterns.md): capture a machine's recipe catalog in a physical pattern, then insert it into a Pattern Provider.
- [All Pattern Linker and Binder](pattern_linker.md): supported machine adapters publish live virtual patterns without physical patterns.
- [Tianshu Pattern Router](tianshu_router.md): choose between competing recipes when placing an AE crafting order.
- [Multiblocks and troubleshooting](multiblocks.md): controller selection, recipe viewers and machine inputs.

Craft this guide with a book and a Certus Quartz Crystal. Right-click the guide to open it. GuideME's configurable **Open Guide** key also opens the relevant page while hovering a supported item. Search and navigation work inside the guide.

The Linker is not required for Aggregate Patterns. The Router is optional for both workflows and does not replace a crafting CPU.
