# AE 全样板 0.1.6 纯净视频演示场

这是全新生成的独立存档，旧演示存档不会被覆盖。场内不使用告示牌，全部说明均为面向镜头的浮空文字。

## 五段录制动线

1. **连接与连续绑定**：快捷栏 1 拿绑定器，右击紫色链接器，然后依次 Shift+右击熔炉、高炉、烟熏炉和充能冶炼炉。紫色立体框代表成功。
2. **同产物、多机器优先级**：四台机器背后各有一台独立样板供应器。用生成器分别扫描机器，把铁锭相关聚合样板放入对应供应器，再调供应器优先级；熔炉、高炉和充能冶炼炉会形成同一产物的真实路线竞争，烟熏炉保留为配方类型对照。
3. **生成与样板配置**：快捷栏 2 拿生成器，Shift+右击基础富集工厂；从旁边木桶取配置演示样板，手持右击查看全部选项，再放入右侧样板供应器。
4. **大型科技与全配方兼容**：展示机械动力粉碎轮、磨粉/搅拌/压片设备，Mekanism 粉碎/灌注/气液机器，工业先锋处理设备、神秘农业完整注魔祭坛，以及 Neo ECO 合成子系统。聚合样板可直接放进 ECO 样板总线，其中可由 ECO 工作者执行的合成子样板会正常发布到网络；同时证明 JEI/EMI 扫描不依赖机器白名单。
5. **天枢路由与实时重算**：右击路由器查看默认配置；在终点合成终端搜索“紫水晶碎片”，下单 16 个，在确认页临时拖动优先级并观察原料列表实时改变。
